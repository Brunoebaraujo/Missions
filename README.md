# Missions

Minimal Phase 0 scaffold for the Missions web application.

## Scope

This scaffold intentionally includes only the baseline application shell and project tooling. It does not include domain features such as authentication, groups, missions, XP, rankings, templates, database schema, or row-level security.

## Local validation

Install dependencies and run the standard checks locally:

```bash
npm install
npm run typecheck
npm run lint
npm run build
```

> Note: dependency installation and build validation may fail in restricted environments where npm registry access is blocked by proxy policy.
